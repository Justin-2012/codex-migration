# Security and private data

Migration bundles, backups, chats, attachments and result reports may contain secrets even when credential files are excluded. Keep them private. Never attach them to an issue or pull request.

For a suspected vulnerability, use GitHub's private vulnerability reporting if enabled on this repository. If it is unavailable, open only a minimal issue asking for a private reporting channel; do not publish exploit details or private data. Ordinary issues may contain app versions and redacted error summaries.

Only v0.1.0 is currently available as an experimental preview. No long-term support or Apple notarization is claimed. Check release hashes, preserve source data and target backups, and respect blocked compatibility checks.
